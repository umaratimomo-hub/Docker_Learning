Technology Stack

The tools behind
the application.

Each component has a specific responsibility within the application architecture.

PY

Python

Provides the programming language for the application and its backend logic.

FL

Flask

Provides the lightweight web framework responsible for handling HTTP requests and rendering templates.

RD

Redis

Provides fast in-memory storage and the atomic INCR operation used by the counter.

DK

Docker

Packages the application and supporting services into reproducible containers.

DC

Docker Compose

Defines and orchestrates the Flask, Redis and Nginx services.

NG

Nginx

Provides a reverse proxy and a single entry point to the application.
