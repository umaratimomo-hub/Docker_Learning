Request Flow

Follow the
request.

A request to the visitor counter travels through the application stack before the updated value is returned to the browser.

01

User requests /count

The browser sends an HTTP request to the visitor counter endpoint.

02

Nginx receives the request

Nginx acts as the reverse proxy and forwards the request to Flask.

03

Flask processes the request

Flask executes the /count route and communicates with Redis.

04

Redis increments the counter

Redis atomically increments the visits key.

05

Flask renders the response

The updated visitor count is passed to count.html using Jinja.

06

Browser displays the count

The user sees the updated visitor count in the browser.

@app.route ("/count")
def count():
     visits = r.incr( "visits" )
     return render_template( "count.html" , visits=visits)
